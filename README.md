# 👟 Sepatukuid - Premium Sneakers E-Commerce

**Sepatukuid** adalah platform e-commerce modern yang dirancang khusus untuk pecinta sneakers. Dibangun dengan fokus pada pengalaman pengguna yang mulus, desain minimalis yang elegan, dan manajemen operasional yang efisien untuk admin dan petugas.

---

## ✨ Fitur Utama

### 🛒 Sisi Pelanggan (User)
- **Katalog Produk Interaktif:** Penelusuran produk dengan filter kategori, gender, dan pencarian cerdas.
- **Wishlist & Keranjang Belanja:** Simpan produk favorit dan kelola belanjaan dengan sistem AJAX (tanpa reload halaman).
- **Lacak Pesanan Real-time:** Pantau status pengiriman dari persiapan hingga sampai di tujuan.

### 🛡️ Sisi Admin & Petugas (Management)
- **Dashboard Statistik:** Visualisasi data penjualan, jumlah pengguna, dan status pesanan.
- **Manajemen Inventaris:** Kontrol stok berdasarkan varian ukuran, harga, dan diskon.
- **Manajemen Pesanan:** Alur kerja lengkap untuk memvalidasi pembayaran dan memperbarui status pengiriman.
- **Layanan Pelanggan:** Kelola dan balas tiket bantuan pelanggan secara efisien.
- **Role-Based Access:** Pembatasan akses antara Admin (kontrol penuh) dan Petugas (operasional).

---

## 🛠️ Tech Stack

- **Framework:** [Laravel 12.x](https://laravel.com)
- **Language:** PHP 8.2+, JavaScript (ES6+)
- **Styling:** Vanilla CSS (Custom Design)
- **Frontend Tools:** Vite, Blade Templating, FontAwesome 6, Google Fonts (Inter)
- **Database:** MySQL / SQLite
- **Asynchrony:** Fetch API / Axios for seamless interactions
